# 4. Comprueba tu punto de partida

Responde con tus palabras antes de mirar las soluciones.

1. ¿Qué diferencia hay entre Python y VS Code?
2. ¿Qué instala una extensión del editor y qué instala `pip`?
3. Estás viendo `>>>`. ¿Dónde estás y cómo sales?
4. ¿En qué carpeta busca la shell el archivo de `python hola.py`?
5. ¿Por qué un programa sin errores puede dar un resultado incorrecto?
6. Crea una carpeta, entra en ella desde la terminal, comprueba la ubicación y vuelve a la carpeta superior.

<details>
<summary>Respuestas y criterio de avance</summary>

1. Python es el lenguaje; un intérprete lo ejecuta. VS Code permite editar el código y trabajar con el intérprete mediante su extensión.
2. Las extensiones añaden capacidades a VS Code; `pip` instala paquetes en un entorno de Python.
3. Estás en la sesión interactiva de Python. `exit()` vuelve a la shell.
4. Si usas esa ruta relativa, en la carpeta de trabajo actual. PATH se utiliza para localizar el ejecutable `python`.
5. El algoritmo o los datos pueden ser incorrectos aunque el código sea válido.
6. Utiliza la tabla de comandos de la lección anterior y verifica el resultado también con el explorador de archivos.

Puedes avanzar cuando distingas editor, terminal e intérprete y hayas completado la práctica de carpetas. Si necesitas consultar los comandos, es normal: no hace falta memorizarlos.

</details>
