# 0. Antes de escribir código

Este bloque se puede leer en el navegador, antes de instalar nada. Solo necesitas saber abrir una página web y guardar un archivo. No se presupone experiencia con Excel, SQL o programación.

| Orden | Lección | Al terminar podrás… |
|---|---|---|
| 1 | [Qué es programar y qué es Python](01-que-es-programar.md) | Explicar qué problema resuelve un programa |
| 2 | [Lenguaje, intérprete, editor e IDE](02-herramientas.md) | Distinguir las piezas del entorno |
| 3 | [Archivos, carpetas, terminal y CLI](03-terminal-y-archivos.md) | Reconocer dónde escribir cada instrucción |
| 4 | [Comprobación inicial](04-comprueba-lo-aprendido.md) | Decidir si puedes pasar a la instalación |

Dedica unos 45–60 minutos, como orientación. No avances por tiempo: avanza cuando puedas explicar y reproducir lo aprendido.

Después sigue [Preparar el entorno](../Requisitos/README.md). [Volver al curso](../README.md).
