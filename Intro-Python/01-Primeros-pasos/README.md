# 1. Primeros pasos con Python

Antes de empezar: [fundamentos](../00-Fundamentos/README.md), [Python y VS Code instalados](../Requisitos/README.md) y extensión Python. Todavía no necesitas paquetes, notebooks ni una base de datos.

| Orden | Lección | Práctica |
|---|---|---|
| 1 | [Tu primer programa](01-primer-programa.md) | Guardar y ejecutar un archivo |
| 2 | [Valores, variables y entrada](02-valores-y-variables.md) | Un cálculo y un saludo interactivo |
| 3 | [Decisiones, repeticiones y funciones](03-decisiones-y-funciones.md) | Clasificar pedidos y calcular importes |
| 4 | [Leer errores y depurar](04-errores-y-depuracion.md) | Encontrar y corregir un fallo |
| 5 | [Ejercicios y miniproyecto](05-ejercicios.md) | Resolver un resumen de ventas |
| 6 | [Del script al notebook](06-del-script-al-notebook.md) | Ejecutar celdas y controlar su estado |

Tiempo orientativo: 3–4 horas, adaptable al grupo, más la instalación. Puedes repartirlo en sesiones cortas. En cada ejemplo: predice el resultado, ejecútalo, cambia un dato y explica qué ha cambiado.

Los [ejemplos](ejemplos/) funcionan con la biblioteca estándar. Guarda tus versiones en una carpeta `mis-ejercicios` dentro de `Intro-Python`. Las [soluciones](soluciones/) se consultan después de intentarlo.
