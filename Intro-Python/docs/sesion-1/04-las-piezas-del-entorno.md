# 4 · Las piezas de tu entorno

[Inicio](../README.md) › [Sesión 1](README.md) › Las piezas de tu entorno

**Tiempo aproximado:** 5 minutos

## Antes de instalar, entender

En el siguiente apartado vas a instalar **cuatro programas**. Antes conviene saber **qué es cada uno y para qué sirve**, porque la mayoría de los problemas de quien empieza vienen de confundirlos. Usaremos una comparación con una cocina.

## La cocina de la programación

| En la cocina... | En programación... | Qué es | En este seminario |
|---|---|---|---|
| La **receta** escrita | El **código** | Las instrucciones que escribes | `print("Hola")` |
| El **cuaderno** donde apuntas recetas | El **archivo** `.py` | Donde guardas el código | `hola.py` |
| El **cocinero** que sigue la receta | El **intérprete** de Python | El programa que lee tu código y lo ejecuta (ya sabes cómo: [apartado 3](03-como-entiende-el-ordenador-un-programa.md)) | Python, descargado de python.org |
| La **encimera** con buena luz y utensilios a mano | El **editor** o **IDE** | El programa donde escribes y organizas tu código | Visual Studio Code (VS Code) |
| Un **utensilio especializado** | Una **extensión** | Un añadido que hace que el editor "entienda" Python | La extensión *Python* de Microsoft |
| El **historial de versiones** de cada receta, con fecha y quién la cambió | **Git** | El programa que guarda el historial de cambios de tus archivos | Git (lo usarás en la sesión 2) |
| La **ventanilla** donde das órdenes por escrito | La **terminal** | Una ventana para dar órdenes al ordenador escribiendo | PowerShell (Windows) o Terminal (Mac) |

> **Idea clave.** **VS Code no es Python.** VS Code es solo el sitio donde escribes. Quien ejecuta tu código es el intérprete de Python. Por eso hay que instalar los dos por separado, más la extensión que los conecta.

> **Cuidado.** **Visual Studio Code** y **Visual Studio** son dos programas distintos de Microsoft. Nosotros usamos Visual Studio **Code**, que es más ligero y gratuito.

## Qué pasa cuando "ejecutas" un programa

1. Escribes tu código en VS Code y lo **guardas** en un archivo en disco, por ejemplo `hola.py`.
2. Pulsas el botón de ejecutar (▶).
3. VS Code le pide al **intérprete de Python** que lea tu archivo.
4. Python lo traduce a bytecode y lo ejecuta, instrucción a instrucción, de arriba abajo.
5. Lo que tu programa muestra aparece en la **terminal**, en la parte inferior de VS Code.

## Algunas palabras que vas a oír

No hace falta memorizarlas. Vuelve aquí (o al [glosario](../glosario.md)) cuando las necesites.

| Palabra | Significado sencillo |
|---|---|
| **Ejecutar** (o "correr", del inglés *run*) | Pedirle al ordenador que haga lo que dice el código |
| **Script** | Un archivo con código que se ejecuta de principio a fin |
| **Shell** | El programa que hay dentro de la terminal y que entiende tus órdenes (en Windows se llama PowerShell) |
| **Comando** | Una orden que escribes en la terminal, como `python --version` |
| **REPL** | Un modo en el que Python ejecuta las líneas una a una, según las escribes. Se reconoce por el símbolo `>>>` |
