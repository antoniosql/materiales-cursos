# Python para analítica de datos y Machine Learning

Materiales de las sesiones de Python orientadas a **analítica de datos y Machine Learning**: acceso a datos, calidad y preparación, análisis exploratorio, codificación y escalado de variables y primeros modelos.

Parte del nivel que se alcanza en el [seminario de introducción a Python](../Intro-Python/): conviene haberlo completado antes.

> **En preparación.** Este curso se está reescribiendo sobre el caso **FraSoHome** y su base de datos en Azure SQL. De momento contiene los notebooks de partida del curso anterior.
