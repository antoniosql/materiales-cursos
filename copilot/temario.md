# Formación: Microsoft Copilot y Agentes IA para Equipos Directivos

**Duración**: 12 horas

**Formato**: 3 sesiones de 4 horas

**Perfil**: Comité de Dirección, responsables funcionales y mandos intermedios

**Metodología**: Exposición ejecutiva + demostraciones + talleres guiados + laboratorio de diseño de agentes

## Objetivos de aprendizaje

Al finalizar la formación, los participantes serán capaces de:

- Comprender el ecosistema Microsoft Copilot y su propuesta de valor empresarial.
- Utilizar técnicas avanzadas de prompting orientadas a negocio.
- Identificar oportunidades de automatización y aumento de productividad mediante IA.
- Conocer las capacidades y diferencias entre Microsoft 365 Copilot, Copilot Chat, Agent Builder y Copilot Studio.
- Aplicar una metodología estructurada para descubrir casos de uso.
- Clasificar y priorizar oportunidades de agentes IA.
- Diseñar y construir un agente funcional alineado con un proceso de negocio.

## SESIÓN 3 Descubrimiento, Priorización y Construcción de Agentes

**Duración**: 4 horas

### Parte 1. Metodología de Descubrimiento y Clasificación

**Duración**: 2 horas

**Bloque 1. Framework de descubrimiento de oportunidades**

*Paso 1. Inventario de procesos*

Identificar:

- Procesos repetitivos.
- Consultas frecuentes.
- Actividades de búsqueda de información.
- Tareas documentales.
- Procesos de aprobación.

*Paso 2. Clasificación de casos*

Matriz:

| Tipo	| Complejidad	| Impacto
|---|---|---|
|Asistente documental	|Baja	|Media
|FAQ corporativa | Baja	| Media
Soporte a procesos	| Media	| Alta
Agente de decisión	| Media	|Alta
Agente transaccional	| Alta	|Muy alta

*Paso 3. Priorización*

Variables:

- Valor generado.
- Frecuencia.
- Volumen.
- Facilidad de implantación.
- Disponibilidad de datos.
- Riesgos.

**Taller**

Cada grupo selecciona:

- Un proceso.
- Un caso de uso.
- Un conjunto de usuarios.
- Un conjunto de fuentes documentales.

*Parte 2. Laboratorio de Construcción*

**Duración**: 2 horas

Trabajo por equipos

Cada grupo diseña un agente para un proceso real de Profand.

Entregables mínimos
1. Ficha del agente
- Nombre.
- Objetivo.
- Usuarios.
- Problema que resuelve.
- Beneficios esperados.
2. Prompt de sistema
- Rol.
- Alcance.
- Restricciones.
- Formato de respuesta.
3. Fuentes de conocimiento
- SharePoint.
- Documentación.
- Procedimientos.
- Manuales.
4. Prototipo funcional

Creación mediante: Agent Builder o
Copilot Studio.
5. Pitch final (5 minutos)

Presentación del agente:

- Problema.
- Solución.
- Beneficio.
- Próximos pasos.
